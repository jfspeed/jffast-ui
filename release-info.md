## 3 运行前提

| 项              | 默认值                                      | 说明                                                                                                                                                                |
| --------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| dev 端口 / 代理 | `7201` → `http://localhost:7200/jffast-api` | `.env.development` 可覆盖                                                                                                                                           |
| 后端            | `jffast`（端口 7200）                       | 登录 / 菜单 / 字典依赖                                                                                                                                              |
| RSA 公钥        | 由后端 `GET /sys/rsaPublicKey` 动态下发     | **release 构建必填** `VITE_RSA_PUBLIC_KEY`（空值、或不是合法 RSA 公钥即 Base64(X.509 SPKI DER) 校验失败）；仓库不存密钥字面量；登录侧无公钥直接拒绝提交，不降级明文 |

## 5 迁移说明（自 jpfast 旧版项目）

1. API 前缀 `/jpfast-api` → `/jffast-api`（与后端品牌重命名同步；网关 / 代理转发路径一并改）。
2. 依赖安全升级（axios ^1.20、vite ^6.4.x 等，见 CHANGELOG）；`vue-tsc` 钉 `3.3.11`（3.3.12 有模板闭包回归）。
3. 登录验证码：改为按后端失败次数自动显示（此前文案称「未启用」，本包起开箱可用）。
4. 仪表盘等页面文案迁移 i18n 词典（`shared/src/locales/lang/`），自定义改动注意合并冲突。

## 6 已知限制

- 国际化为中英词典**逐步覆盖**，非全量硬编码替换。

- E2E（Playwright，`e2e/`）为登录 / 列表 / 查询三条冒烟用例，需前后端联调环境（`npm run test:e2e`）；其余单测为 Vitest。
